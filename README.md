# SQUAD NINE — NPB スタメンメーカー

日本プロ野球版の「スタメンを組んで共有する」アプリ。[SQUAD XI](https://squadxi.futbol/) の野球版。

## できること

- **守備位置ビュー** — 野球場のイラスト上に9つのポジションを配置。円をタップして選手を選ぶ
- **球場デザイン** — セ・リーグ6球団の本拠地を元にした6種類（「…」→ 球場デザイン）。`field-samples.html` で並べて比較できる

  | ID | 表記 | 内野 | 土の色 | フェンス前の土 | フェンス |
  |---|---|---|---|---|---|
  | `koshien` | 甲子園 | 全面土 | 黒土 | あり（黒土） | 濃緑 |
  | `tokyodome` | 東京ドーム | 全面芝＋塁とマウンドだけ円形の土 | 明るい茶 | なし | 濃緑 |
  | `vantelin` | バンテリン | 全面土 | オレンジ茶 | なし | 濃紺 |
  | `jingu` | 神宮 | 全面土 | 赤茶 | あり（広い） | 濃緑 |
  | `mazda` | マツダ | 内野芝＋土のベースパス | 赤茶 | あり | 濃緑 |
  | `yokohama` | 横浜 | 全面土 | オレンジ赤茶 | あり | 濃紺 |
  | `mizuhopaypay` | みずほPayPay | 人工芝＋塁とマウンドだけ土 | 塁=赤茶 / マウンド=黒土 | あり | 濃い緑 |
  | `kyocera` | 京セラ | 人工芝＋塁とマウンドだけ土 | 赤茶 | あり | 青 |
  | `zozo` | ZOZO | 神宮と同一 | 赤茶 | あり | 青 |
  | `belluna` | ベルーナ | 神宮と同一 | 赤茶 | あり | 緑 |
  | `rakuten` | 楽天モバイル | 神宮型・塁まわりも走路も同色 | 黒土 | あり（赤茶） | 緑 |
  | `escon` | エスコンF | 神宮型・全て同色 | 赤茶 | あり | ほぼ黒の濃い緑 |

  外野は既定では半径一定の円弧。`escon` のみ `outfield: [[角度, 距離], …]`（中堅0度・左翼が負）で
  多角形に差し替えている。同じ書式で他球場のいびつな外野も表現できる。

- **DH あり / DH なし** の切り替え（打順が自動で組み替わる）
- **打順表** — 打順・守備位置・選手名の表。ドラッグまたは ▲▼ で入れ替え
- **守備位置の表記切替** — ボタン1つで `投 捕 一 二 三 遊 左 中 右 指`（漢字1文字）⇄ `ピッチャー キャッチャー ファースト …`（カタカナ）
- **選手の入れ替え・削除** — 盤面の円と打順表のどちらからも `×` で外せる。盤面右上の **リセット** で全消し
- **選手検索** — 漢字・ふりがな（ひらがな/カタカナ）・背番号で検索。「おかもと」「オカモト」「岡本」いずれでも引ける
- **選手写真** — Web検索 / カメラ・フォルダから選択 / クリップボードから貼り付け（Ctrl+V）。丸くトリミング（ズーム・ドラッグ位置調整）して保存
- **リンク共有** — 共有モーダルの「リンクをコピー」でスタメンをURLに載せて渡せる。開くと同じ布陣・打順・球場デザインが復元される
- **SNSへ共有** — 「Xで共有」「Instagram」ボタン。スマホでは画像付きでOSの共有シートが開き、そのまま各アプリへ。PCでは画像を保存して投稿画面を開くフォールバック
- **おまかせ配置** — 球団を選んで「⚡おまかせ」でプリセットのスタメンを自動配置（プリセットは `data/presets.js` に定義。未定義の球団は「準備中」表示）
- **PWA** — manifest・アイコン設定済み。ホーム画面に追加するとアプリとして開く
- **共有する** — 用途別のサイズで PNG を書き出し。対応端末では OS の共有シートから直接SNSへ
  | プリセット | サイズ | レイアウト |
  |---|---|---|
  | Instagram | 1080×1350 (4:5) | 盤面の下に打順2列 |
  | 正方形 | 1080×1080 (1:1) | 盤面の下に打順2列 |
  | ストーリーズ | 1080×1920 (9:16) | 盤面の下に打順1列（大きめ） |
  | X (Twitter) | 1600×900 (16:9) | 盤面の右に打順1列 |
- スタメン・写真はブラウザの localStorage に自動保存（サーバー不要・端末内のみ）

## 起動

`index.html` を直接開いても動くが、ローカルサーバー経由が確実：

```bash
powershell -ExecutionPolicy Bypass -File tools\serve.ps1
```

→ http://localhost:8765/

## 選手データ

出典: [日本野球機構 (NPB) 選手一覧](https://npb.jp/bis/teams/) — 2026年8月1日現在

**1065名**（12球団 / 支配下 836・育成 229）。各選手の項目：

| キー | 内容 |
|---|---|
| `id` | NPB の選手ページID |
| `name` / `number` | 選手名（姓名は全角スペース区切り）/ 背番号 |
| `team` / `teamShort` / `teamId` / `league` | 所属チーム（正式名 / 略称 / コード / セ・パ） |
| `group` | 投手 / 捕手 / 内野手 / 外野手 |
| `roster` | 支配下 / 育成 |
| `birth` | 生年月日 `yyyy.MM.dd` |
| `height` / `weight` | 身長(cm) / 体重(kg) |
| `throws` / `bats` | 投 / 打（`右` `左` `左右`＝スイッチ） |
| `kana` | ふりがな（例: `まる・よしひろ`）— 検索用 |
| `photoUrl` | NPB公式の選手写真URL（**未使用**。利用は権利確認のうえ判断すること） |
| `note` | 備考 |

データの更新（シーズン中の入退団・育成契約の変動に追随）：

```bash
powershell -ExecutionPolicy Bypass -File tools\fetch-npb.ps1
```

12球団のページを取得し直して `data/npb-players.json`（整形版）と
`data/npb-players.js`（アプリが読む圧縮版）を再生成する。

そのあと、ふりがなと写真URLを追記する（選手ページを1件ずつ取得。初回は約4分、2回目以降はキャッシュを使う）：

```bash
powershell -ExecutionPolicy Bypass -File tools\fetch-details.ps1
```

## ファイル構成

```
index.html              画面
styles.css              スタイル
app.js                  ロジック（状態・描画・写真・PNG書き出し）
field.js                球場イラストのSVG生成（デザイン4案）
field-samples.html      球場デザインの見比べ用ページ
data/npb-players.js     アプリが読み込む選手データ
data/npb-players.json   同じ内容の整形JSON（他用途向け）
tools/fetch-npb.ps1     NPB公式から名簿を再取得
tools/fetch-details.ps1 ふりがな・写真URLを追記
tools/serve.ps1         ローカル静的サーバー (:8765)
```

## 設定

`app.js` 冒頭の `SHARE_SITE` が共有画像の右下に焼き込まれるサイト名。公開ドメインが決まったら書き換える。

## メモ

- 写真の「Webで画像を検索」は Google 画像検索を別タブで開くだけ。表示された画像を
  右クリック →「画像をコピー」→ アプリに戻って **Ctrl+V** で貼り付ける。
  （ブラウザのCORS制約により、外部画像を直接読み込んで書き出すことはできないため）
- 現状の実装依存: ビルド不要の素のHTML/CSS/JS。Node も npm も使っていない。
